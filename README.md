# БРАТВА — монополия 90-х (сетевая)

Сервер запускается на твоём ПК, друзья заходят с телефонов через браузер. Ничего не надо ставить на телефоны, аккаунты и Firebase не нужны.

## Запуск за 2 минуты

1. Поставь **Node.js LTS** (один раз): https://nodejs.org → большая зелёная кнопка «LTS».
2. Распакуй архив в любую папку.
3. Запусти:
   - **Windows** — двойной клик по `start.bat`
   - **macOS** — двойной клик по `start.command` (если ругается — правый клик → «Открыть»)
   - **Linux** — `./start.sh`
4. В окне появятся адрес и QR-код. На ПК открой `http://localhost:3000`.
5. Создай сходку → в лобби будет QR-код с кодом комнаты. Друзья наводят камеру — и они в игре.

> Windows при первом запуске спросит про брандмауэр — поставь галочку **«Частные сети»** и нажми «Разрешить». Без этого телефоны не достучатся.

## Как друзьям зайти

**Все в одном Wi-Fi** (дома, на тусе) — просто QR из лобби. Это самый быстрый вариант, задержек нет.

**Друзья в других местах** — нужен «тоннель», который делает твой ПК видимым из интернета. Варианты:

| Способ | Что сделать |
|---|---|
| **Radmin VPN** (бесплатно, популярен у геймеров) | Ставите все, ты создаёшь сеть, друзья в неё заходят. Дальше играете как в одном Wi-Fi по адресу `http://<твой Radmin IP>:3000` |
| **Tailscale** | То же самое, ставится на ПК и на телефоны |
| **Cloudflare Tunnel** | Поставь `cloudflared`, запусти `share.bat` / `share.sh` — получишь ссылку `https://….trycloudflare.com`, кидаешь её друзьям |

Ссылку из тоннеля можно открыть у себя, создать сходку — QR в лобби уже будет с этой ссылкой.

## Добавить на экран «Домой»

iPhone: Safari → «Поделиться» → «На экран Домой». Samsung: меню браузера → «Добавить на главный экран». Откроется на весь экран, как приложение.

## Правила коротко

- Две кости, дубль — ещё бросок, три дубля — к ментам.
- Свободную точку берёшь под крышу, свою прокачиваешь до ★★★ (рента ×2 за звезду). Весь район одного цвета — рента ×2.
- На чужой точке: платишь долю или забиваешь **стрелку** (кубик + авторитет + братки). Выиграл — точка твоя.
- **Качалка** — братки: садятся вместо тебя и дают силу на стрелках.
- **Розыск** 🔥 растёт от покупок, прокачек, стрелок и казино. На 5 огнях выезжает **ОМОН** и едет против хода.
- Деньги кончились — точки сами уходят банку за полцены. Совсем в минусе — вылетаешь.
- Победа: последний выживший или самый богатый, когда кончатся круги (10/20/30, задаёт босс в лобби).

## Для разработки

```
npm install
npm start          # сервер на порту 3000 (PORT=4000 npm start — другой порт)
npm test           # прогон 12 партий ботами в ускоренном режиме
```

Файлы: `server.js` — вся логика игры; `public/` — клиент (`game.js`, `style.css`, `sound.js`), `public/shared.js` — поле и цены (общие для сервера и клиента). Цены, ренты и константы меняются в `shared.js`.
